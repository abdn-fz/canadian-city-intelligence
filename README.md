# Canadian City Intelligence

🚧 Work in Progress

This project is currently under development. The repository is updated progressively as data preparation, exploratory analysis, statistical analysis, SQL analysis, machine learning, and visualization components are completed.

## Dataset

The datasets used in this project come from the following Kaggle dataset:

**Canadian City Comparison Data** — Colby Jamieson  
https://www.kaggle.com/datasets/colbyjamieson/canadian-city-comparison-data

The dataset contains socioeconomic indicators for nine major Canadian cities, including:

- Population
- Unemployment rate
- Crime rate
- Consumer Price Index (CPI)
- Housing Price Index

The original datasets are provided in CSV format and are cleaned and transformed in this project for further analysis.
